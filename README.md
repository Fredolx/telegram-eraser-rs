# telegram-eraser-rs

Simple TUI made in Rust to mass-delete messages from your telegram account.

# Install

## Prebuilt binary

With [cargo-binstall](https://github.com/cargo-bins/cargo-binstall):

```sh
cargo binstall --git https://github.com/Fredolx/telegram-eraser-rs telegram-eraser
```

## From source

```sh
cargo install --git https://github.com/Fredolx/telegram-eraser-rs --locked
```

## Manual download

Download the zip for your platform from the [latest release](https://github.com/Fredolx/telegram-eraser-rs/releases/latest)
