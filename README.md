# telegram-eraser-rs

Simple TUI made in Rust to mass-delete messages from your telegram account.

# Install

## Prebuilt binary

With [cargo-binstall](https://github.com/cargo-bins/cargo-binstall):

```sh
cargo binstall --git https://github.com/Fredolx/telegram-eraser-rs telegram-eraser
```

Prebuilt binaries are available for Linux, macOS and Windows. On other platforms, cargo-binstall builds from source instead.

## From source

```sh
cargo install --git https://github.com/Fredolx/telegram-eraser-rs --locked
```

## Manual download

Download the zip for your platform from the [latest release](https://github.com/Fredolx/telegram-eraser-rs/releases/latest), extract it and put `telegram-eraser` somewhere in your `PATH`.
